# Aplicaciones

## Tracer bullet actual

- `api/`: FastAPI con `/health` y estado vacío explícito para `/api/v1/inventory`.
- `web/`: Next.js App Router con una pantalla inicial del producto.

Este vertical no afirma que exista persistencia, autenticación, SALMI ni ML implementados. Es la primera frontera ejecutable para conectar requisitos, arquitectura, código y pruebas.
