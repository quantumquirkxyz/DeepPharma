# Arquitectura

La arquitectura candidata sigue un monolito modular en capas con puertos y
adaptadores. Este directorio contiene el documento RUP, vistas, modelo de
datos físico y lógico, escenarios de calidad y riesgos.

La decisión arquitectónica todavía es una propuesta. Las decisiones
aceptadas se mantienen en [`../adr/`](../adr/).
