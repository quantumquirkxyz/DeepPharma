# CU-07 — Validar datos de inventario

**Versión:** 0.1
**Estado:** Borrador en refinamiento
**Clasificación:** Caso de uso funcional candidato
**Fuente:** `CU-01`, `SRC-05`, `SRC-07`, reglas de calidad de datos

## 1. Objetivo

Verificar que un conjunto de datos de inventario cumple el esquema, las reglas de integridad y los criterios mínimos de calidad antes de quedar disponible para preprocesamiento o entrenamiento.

## 2. Actores

- **Actor principal:** `ACT-03 Ingeniero de Machine Learning`.
- **Actor secundario:** `ACT-01 Administrador del sistema`.
- **Caso relacionado:** `CU-01 Registrar datos históricos de inventario`.

## 3. Disparador

El actor solicita validar un conjunto registrado o el sistema inicia la validación como paso posterior al registro.

## 4. Precondiciones

- Existe un conjunto registrado.
- El conjunto tiene procedencia y versión.
- Existe un esquema de validación.
- Las reglas de calidad están disponibles.

## 5. Postcondiciones

### Aprobación

- Se registra el resultado de validación.
- El conjunto queda marcado como `validado`.
- Se documentan métricas de calidad y advertencias.
- El conjunto puede pasar a `CU-08`.

### Rechazo

- El conjunto queda marcado como `rechazado` o `requiere corrección`.
- Se registran errores, filas y campos afectados.
- No se permite utilizarlo para entrenamiento.

## 6. Flujo básico

1. El actor selecciona un conjunto registrado.
2. El sistema carga el esquema esperado.
3. El sistema verifica columnas obligatorias y tipos.
4. El sistema verifica identificadores y fechas.
5. El sistema verifica valores nulos, duplicados y rangos.
6. El sistema calcula indicadores de calidad.
7. El sistema clasifica errores y advertencias.
8. El sistema registra el resultado.
9. El sistema muestra el resumen y el detalle.
10. Finaliza el caso de uso.

## 7. Flujos alternos

### FA-01 — Validación parcial

El actor solicita validar únicamente un período, centro o conjunto de columnas. El sistema registra el alcance de la validación.

### FA-02 — Revalidación

El actor corrige el conjunto y solicita una nueva validación. El sistema conserva la versión anterior y crea un nuevo resultado.

### FA-03 — Advertencias aceptables

El conjunto contiene advertencias no bloqueantes. El actor autorizado las revisa y el sistema registra la justificación antes de aprobar.

## 8. Flujos de excepción

### FE-01 — Esquema incompatible

El sistema identifica columnas faltantes, adicionales o tipos incompatibles y rechaza la validación.

### FE-02 — Identificadores inválidos

El sistema identifica medicamentos o centros inexistentes y rechaza los registros afectados o el conjunto completo según la política aprobada.

### FE-03 — Fechas inválidas

El sistema identifica fechas ausentes, imposibles o fuera del período permitido.

### FE-04 — Calidad insuficiente

El sistema calcula una calidad inferior al umbral aprobado y marca el conjunto como no apto.

## 9. Reglas provisionales

- `RN-CU07-01`: las columnas obligatorias deben estar definidas en el esquema versionado.
- `RN-CU07-02`: un conjunto rechazado no puede entrenar modelos.
- `RN-CU07-03`: los duplicados, nulos y valores atípicos deben registrarse.
- `RN-CU07-04`: corregir datos crea una nueva versión.
- `RN-CU07-05`: los umbrales de calidad deben ser configurables y trazables.
- `RN-CU07-06`: validar no significa corregir silenciosamente los datos.

## 10. Requisitos relacionados

- `RF-07` Validar conjuntos de datos contra un esquema versionado.
- `RNF-07` Generar resultado de validación reproducible.
- `RN-07` Preservar procedencia y versiones.

## 11. Escenarios candidatos

- `ESC-CU07-01` Validación exitosa.
- `ESC-CU07-02` Columnas obligatorias faltantes.
- `ESC-CU07-03` Datos duplicados y nulos.
- `ESC-CU07-04` Revalidación de una versión corregida.

## 12. Criterios de aceptación preliminares

- Se valida contra un esquema versionado.
- Los errores son identificables por campo y registro cuando sea posible.
- El sistema no corrige silenciosamente.
- Los resultados quedan registrados.
- Solo conjuntos validados pueden pasar a preprocesamiento o entrenamiento.

## 13. Pendientes
