# CU-13 — Consultar inventario actual

**Versión:** 0.1
**Estado:** Borrador en refinamiento
**Clasificación:** Caso de uso funcional candidato
**Fuente:** `CU-05`, `SRC-05`, requisitos de consulta

## 1. Objetivo

Permitir que un usuario autorizado consulte el inventario actual por medicamento, centro de salud, fecha y estado de actualización.

## 2. Actores

- **Actor principal:** `ACT-02 Farmacéutico`.
- **Actores secundarios:** `ACT-05 Administrador de farmacia`, `ACT-01 Administrador del sistema`, `ACT-03 Ingeniero de Machine Learning`.

## 3. Disparador

El actor solicita consultar el estado actual del inventario.

## 4. Precondiciones

- El actor está autenticado.
- El actor posee permisos sobre el ámbito solicitado.
- Existen registros o el sistema puede informar que no hay datos.

## 5. Postcondiciones

- El sistema presenta únicamente datos autorizados.
- Cada resultado muestra fecha, fuente y estado de actualización.
- Una consulta sin resultados se representa como estado vacío.

## 6. Flujo básico

1. El actor accede a la consulta de inventario.
2. El sistema verifica permisos y ámbito.
3. El sistema muestra filtros disponibles.
4. El actor selecciona filtros.
5. El sistema valida los filtros.
6. El sistema recupera los registros actuales.
7. El sistema muestra medicamento, centro, cantidad, unidad, fecha, fuente y estado.
8. El actor puede seleccionar un registro para consultar su historial.
9. Finaliza el caso de uso.

## 7. Flujos alternos

### FA-01 — Consulta sin filtros

El sistema aplica el ámbito permitido del actor y solicita paginación o filtros cuando el volumen sea alto.

### FA-02 — Consultar historial

El actor selecciona un registro y el sistema muestra actualizaciones anteriores sin permitir modificarlas desde esta consulta.

### FA-03 — Exportar resultados

El actor solicita exportación y el sistema genera únicamente los datos autorizados.

## 8. Flujos de excepción

### FE-01 — Permiso insuficiente

El sistema rechaza la consulta y no revela datos fuera del ámbito.

### FE-02 — Datos desactualizados

El sistema muestra la antigüedad y estado del último registro válido.

### FE-03 — Error de persistencia

El sistema informa que no puede recuperar los datos y registra el error.

### FE-04 — Filtro inválido

El sistema informa el criterio inválido y solicita corregirlo.

## 9. Reglas provisionales

- `RN-CU13-01`: el actor solo consulta el ámbito autorizado.
- `RN-CU13-02`: cada dato muestra fecha, fuente y estado.
- `RN-CU13-03`: datos desactualizados no se presentan como actuales.
- `RN-CU13-04`: la consulta no modifica inventario.
- `RN-CU13-05`: la exportación respeta los mismos permisos de consulta.

## 10. Requisitos relacionados

- `RF-05` Registrar y consultar inventario actual.
- `RNF-13` Respuesta dentro del tiempo aprobado `[PENDIENTE DE MEDICIÓN]`.
- `RN-13` Protección por ámbito y procedencia.

## 11. Escenarios candidatos

- `ESC-CU13-01` Consulta por centro y medicamento.
- `ESC-CU13-02` Consulta sin resultados.
- `ESC-CU13-03` Consulta de dato desactualizado.
- `ESC-CU13-04` Consulta de historial.
- `ESC-CU13-05` Rechazo por ámbito no autorizado.

## 12. Criterios de aceptación preliminares

- Los resultados se filtran por permisos.
- Se muestran fuente y fecha.
- Los datos desactualizados se identifican.
- La consulta no modifica registros.
- Las exportaciones no exceden el ámbito del actor.
