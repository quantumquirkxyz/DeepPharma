# CU-19 — Configurar fuentes e integraciones

**Versión:** 0.1
**Estado:** Borrador en refinamiento
**Clasificación:** Caso de uso funcional candidato
**Fuente:** `CU-09`, `CU-18`, `SRC-11`, `SRC-12`

## 1. Objetivo

Permitir que un administrador autorizado configure fuentes de datos e integraciones sin exponer secretos ni acoplar el dominio a una tecnología externa.

## 2. Actores

- **Actor principal:** `ACT-01 Administrador del sistema`.
- **Sistema externo configurado:** `EXT-01 SALMI` u otra fuente autorizada.
- **Componente interno:** adaptador de integración.

## 3. Disparador

El administrador solicita registrar, modificar, probar, activar, desactivar o retirar una fuente o integración.

## 4. Precondiciones

- El administrador está autenticado y autorizado.
- Existe un adaptador compatible o se ha aprobado su incorporación.
- El contrato de la fuente está disponible o la integración está marcada como simulada.
- Los secretos pueden gestionarse mediante un mecanismo seguro.

## 5. Postcondiciones

### Éxito

- La fuente queda registrada con estado y versión de configuración.
- La conexión se prueba o queda explícitamente pendiente.
- Se conserva auditoría del cambio.
- `CU-09` puede utilizar la fuente si está activa.

### Fallo

- La configuración anterior permanece activa o se desactiva según política segura.
- Los secretos no se exponen.
- Se registra la causa.

## 6. Flujo básico

1. El administrador accede a configuración de integraciones.
2. El sistema verifica permisos.
3. El administrador selecciona una fuente o crea una nueva.
4. El sistema solicita tipo, adaptador, esquema, frecuencia y estado.
5. El administrador proporciona la configuración no secreta.
6. El sistema referencia secretos mediante el gestor seguro.
7. El sistema valida la configuración.
8. El sistema ejecuta una prueba de conexión o marca la integración como simulada.
9. El sistema muestra el resultado.
10. El administrador confirma.
11. El sistema registra la versión y auditoría.
12. Finaliza el caso de uso.

## 7. Flujos alternos

### FA-01 — Configurar fuente simulada

El administrador registra una fuente de demostración. El sistema la etiqueta como simulada y evita presentarla como integración institucional real.

### FA-02 — Rotar credenciales

El administrador solicita actualizar un secreto. El sistema cambia la referencia sin mostrar el valor anterior ni el nuevo.

### FA-03 — Desactivar integración

El sistema desactiva futuras sincronizaciones y conserva los datos históricos previamente incorporados.

### FA-04 — Probar configuración sin activar

El administrador prueba una configuración sin habilitarla para ejecuciones programadas.

## 8. Flujos de excepción

### FE-01 — Adaptador inexistente

El sistema rechaza la configuración y solicita incorporar un adaptador aprobado.

### FE-02 — Contrato incompatible

El sistema identifica diferencias de esquema o protocolo y no activa la integración.

### FE-03 — Secreto no disponible

El sistema rechaza la conexión sin registrar el secreto.

### FE-04 — Prueba de conexión fallida

El sistema registra el error y mantiene la integración inactiva o pendiente.

### FE-05 — Configuración inválida

El sistema identifica campos inválidos, valores inseguros o frecuencia no permitida.

## 9. Reglas provisionales

- `RN-CU19-01`: los secretos nunca se almacenan en el repositorio ni en texto plano.
- `RN-CU19-02`: una integración simulada debe identificarse como simulada.
- `RN-CU19-03`: una fuente no probada no se activa automáticamente.
- `RN-CU19-04`: cada cambio crea una versión de configuración.
- `RN-CU19-05`: desactivar una fuente no elimina los datos históricos.
- `RN-CU19-06`: el dominio interactúa con interfaces internas, no con proveedores concretos.

## 10. Requisitos relacionados

- `RF-18` Configurar fuentes e integraciones versionadas.
- `RNF-19` Seguridad y auditabilidad de configuración.
- `RN-19` Desacoplamiento de integraciones.

## 11. Escenarios candidatos

- `ESC-CU19-01` Configurar adaptador simulado.
- `ESC-CU19-02` Probar una fuente sin activarla.
- `ESC-CU19-03` Activar fuente autorizada.
- `ESC-CU19-04` Rotar credenciales.
- `ESC-CU19-05` Rechazar contrato incompatible.

## 12. Criterios de aceptación preliminares

- Solo administradores autorizados modifican integraciones.
- Los secretos no se muestran ni se versionan.
- Una fuente simulada se identifica claramente.
- Las configuraciones se versionan.
- Una prueba fallida impide activar la fuente.
- Los datos históricos sobreviven a la desactivación.
