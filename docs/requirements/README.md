# Requisitos

Esta sección contiene los artefactos de requisitos del proyecto:

- actores y objetivos;
- requisitos funcionales y no funcionales;
- reglas de negocio;
- catálogo y especificaciones de casos de uso;
- escenarios;
- RBAC;
- matriz de trazabilidad.
- registro de aclaraciones y decisiones.

Los casos de uso siguen una estructura RUP y permanecen en refinamiento hasta
que sus fuentes, precondiciones, flujos, excepciones, reglas y pruebas estén
cerrados.

Las preguntas que requieren conocimiento institucional están en
`clarifications.md`; no deben resolverse inventando datos.
