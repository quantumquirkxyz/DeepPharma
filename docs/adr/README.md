# Architecture Decision Records

These ADRs are the canonical decision log for DeepPharma. Older architecture
notes under `docs/architecture/` remain compatibility views until migrated.

## Status vocabulary

- `Propuesta`: requires confirmation before becoming a baseline.
- `Aceptada`: confirmed project decision.
- `Reemplazada`: superseded by a later ADR.
