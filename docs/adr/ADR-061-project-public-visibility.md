# ADR-061 — Project público

**Estado:** Aceptada
**Fecha:** 2026-11-26
**Decisor:** Propietario del proyecto

## Decisión

El GitHub Project `DeepPharma — MVP` será público. El repositorio mantiene su
visibilidad actual independiente del Project.

## Consecuencias

- La visibilidad del board facilita la revisión externa del trabajo.
- Los datos sensibles o institucionales no deben almacenarse en Issues,
  comentarios ni campos del Project.
- La información operativa debe seguir las reglas de minimización y privacidad
  del MVP.
